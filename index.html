⚡ Terraform quick command deck

1-click copy reference for daily production terminal commands.
SETUP
terraform init -upgrade

Downloads provider binaries, configures remote backend, and updates version locks (~>).

PREVIEW
terraform plan -out=tfplan

Compares Desired vs Known vs Real. Guarantees: what you review is exactly what executes.

EXECUTE
terraform apply tfplan

Executes the exact saved binary plan contract without prompt, eliminating concurrency drift.

TEARDOWN
terraform destroy

Executes apply in reverse: destroys all managed infrastructure safely with confirmation.

LIST
terraform state list

Lists all resource addresses currently recorded in the state ledger without calling AWS APIs.

RENAME (ZERO REBUILD)
terraform state mv aws_instance.web aws_instance.app

Renames an address inside the state file. Zero cloud rebuild or downtime!

DETACH
terraform state rm aws_vpc.legacy

Stops managing the resource without deleting it from the cloud. Perfect for unlinking.

UNLOCK
terraform force-unlock <LOCK_ID>

Releases an orphaned DynamoDB lock row after confirming the previous runner process is dead.

FORMATTING
terraform fmt -recursive -check

Pre-commit CI gate checking if all .tf files meet canonical indentation standards.

DRIFT AUDIT
terraform plan -refresh-only

Modern replacement for `terraform refresh`. Previews real cloud drift without altering code.

TARGETED RECREATE
terraform apply -replace="aws_instance.web[0]"

Modern replacement for `terraform taint`. Recreates a specific instance in the next plan.

INTERACTIVE REPL
terraform console

Opens interactive evaluation prompt for testing functions, CIDR math, and variable lookups.

THE 7-TIER VARIABLE PRECEDENCE LADDER (HIGHEST WINS)
1. CLI `-var` and `-var-file` flags (Highest — wins everything)
2. `*.auto.tfvars` or `*.auto.tfvars.json` (Loaded alphabetically)
3. `terraform.tfvars.json`
4. `terraform.tfvars` (Auto-loaded by default)
5. Environment variables `TF_VAR_name` (Ideal for CI/CD and secrets)
6. Variable `default` values (Fallback if nothing above is set)
7. Missing value (Prompts interactively at CLI or errors in CI)
